# E-Commerce Sales Data Analysis

## Project Overview

The E-Commerce Sales Data Analysis project focuses on analyzing sales data to identify trends, customer purchasing behavior, and business insights. The project involves data cleaning, preprocessing, exploratory data analysis (EDA), and visualization to understand sales patterns and improve decision-making. Interactive dashboards were created to present insights in a clear and visually understandable format.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Sales trend analysis
* Customer purchasing behavior analysis
* Revenue and profit analysis
* Interactive dashboard visualization

## Technologies Used

* **Programming Language:** Python
* **Platform:** Google Colab
* **Libraries:** Pandas, NumPy, Matplotlib
* **Dashboard Tool:** Bricks AI
* **Dataset:** E-commerce sales dataset

## Installation Steps

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Open the notebook in Google Colab

3. Install required libraries:

```bash
pip install -r requirements.txt
```

4. Run all notebook cells to perform analysis
